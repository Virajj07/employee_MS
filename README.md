# Employee Management System

A simple employee management system built with MySQL database for managing employee records, departments, and basic CRUD operations.

## Features
- Add, update, delete, and view employee records
- Manage employee information including personal details and job information
- MySQL database integration
- Basic employee search and filtering

## Project Structure
- `employee-management-mysql/` - Contains the main application code and database scripts

## Getting Started
1. Clone this repository
2. Navigate to the `employee-management-mysql` directory
3. Set up MySQL database using the provided schema
4. Configure database connection
5. Run the application

## Requirements
- MySQL Server
- Python 3.x (if using Python implementation)
- Required dependencies (see employee-management-mysql directory for details)
